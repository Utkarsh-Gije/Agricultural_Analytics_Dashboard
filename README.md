# Agricultural Analytics Dashboard

An interactive Power BI dashboard for analyzing agricultural performance through three key metrics:

- **Crop Yield** – measures crop output relative to cultivated area.
- **Production Area** – tracks the land area used for crop production.
- **Production Revenue** – analyzes the revenue generated from agricultural production.

## Project file

Open `Agriculture_Analytics_Dashboard.pbix` using Microsoft Power BI Desktop.

## Repository structure

```text
Agricultural_Analytics_Dashboard/
├── Agriculture_Analytics_Dashboard.pbix

```

## Data

Place the source dataset in the `dataset/` folder after confirming which file and fields are used by the Power BI report. No separate CSV has been included because the source dataset has not been provided independently.

## Screenshots

Add dashboard screenshots to `screenshots/` to make the report easier to preview on GitHub.
